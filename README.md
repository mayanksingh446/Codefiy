# 🤖 Codeify – AI Code Reviewer

Codeify is an AI-powered code review application that helps developers analyze, review, and improve their code. It uses Google's Gemini API to provide intelligent code feedback, identify potential issues, and suggest improvements.

## 🚀 Live Demo

**[Visit Codeify – AI Code Reviewer](https://codefiy-frontend.onrender.com/)**

## ✨ Features

- **AI-Powered Code Review:** Analyze code using Google's Gemini API.
- **Code Editor:** Write and edit code using the Monaco Editor.
- **Code Analysis:** Identify potential errors, bugs, and coding issues.
- **Code Improvement:** Get AI-generated suggestions to improve code quality.
- **Markdown Support:** Display AI-generated reviews in a readable format.
- **Interactive Interface:** Simple and developer-friendly user interface.
- **Responsive Design:** Smooth experience across different screen sizes.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd Codeify
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 4. Install Backend Dependencies

```bash
cd backend
npm install
```

### 5. Configure Environment Variables

Create a `.env` file in the backend directory:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Add other required environment variables if applicable.

### 6. Run the Application

Start the backend server:

```bash
npm start
```

Start the frontend:

```bash
npm run dev
```
